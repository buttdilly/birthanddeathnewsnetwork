# BirthandDeathNewsNetwork.com

A deliberately chaotic, low-budget, DIY parody news site. Everything is static: one `index.html` plus the `img/` folder. No build step.

## What's inside
- Crypto ticker, rotating ads, old-school frames with homemade scrollbars, and a draggable floating menu
- Satirical article pages: CampUs™, nightmares, the Miracle Hospice and more
- A fake chatroom overrun by bots (`#chat`)
- Games: **BIRTH TIME™** (`#birth-time`), **Dog Garden** (`#dog-garden`), **Ugly American Baby K-Pop Star Generator GPT** (`#kpop-generator`)

## Hosting
Turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root). Or open `index.html` locally in any browser.

All content is fiction and parody.
